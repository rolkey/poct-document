# 4.1 人员管理模块

建立覆盖 POCT（即时检验）操作人员全生命周期的电子档案系统，实现人员基础信息、资质、培训、考核、授权等要素的数字化、集中化管理，提升管理的规范性、可追溯性与查询效率，确保检测质量与合规要求。

---

## 4.1.2 资质管理

用于管理人员持有的各类从业与专业资格证书。

### 证书类型

| 证书类型 | 关键字段 |
|----------|----------|
| 执业医师/护士证书 | 执业证书编号、发证机构、有效期 |
| 医学检验或相关技术资格证书 | 等级、编号、有效期 |
| POCT 专项培训合格证书 | 培训内容、培训单位、考核成绩、有效期 |
| 其他院内/院外特定 POCT 仪器/项目认证 | 如血气、血糖、凝血等 |

### 功能要求

- 支持上传证书电子版（图片或 PDF）
- 支持设置证书有效期及临近到期提醒（如提前 90 天预警）
- 支持按证书类型、有效期状态（有效 / 即将到期 / 已过期）筛选
- 资质过期时系统自动标记并限制相关授权

## 4.1.3 授权管理

基于人员资质与考核情况，进行动态授权与权限控制。

### 授权类型

| 授权类型 | 说明 |
|----------|------|
| 操作授权 | 可操作哪些 POCT 设备或项目（如血糖仪、血气分析仪等） |
| 报告权限 | 是否可审核/发布/修改检测报告 |
| 质控权限 | 是否可执行或查看质控记录 |
| 管理权限 | 是否可查看/导出档案数据 |

### 管理逻辑

- **授权前提**：必须满足该设备/项目所需的资质与培训，且考核合格
- **授权有效期**：可设置起止时间，支持自动到期停权
- **复训机制**：支持定期（如每年）复训与再授权机制
- **临时授权**：支持借调、轮转场景的临时授权与批量授权
- **审计追踪**：所有授权变更自动生成审批记录与操作日志

### 功能要求

- 按人、按设备/项目、按权限类型组合授权
- 授权流程图支持：申请 → 科室主管审核 → 检验科/质量管理部门确认
- 临近到期自动提醒（系统消息或邮件）

## 4.1.4 档案查询与导出打印

支持多条件的灵活检索与档案输出。

### 查询维度（支持组合查询）

| 维度 | 说明 |
|------|------|
| 工号、姓名、部门 | 人员基本信息 |
| 职称级别 | |
| 资质类型及有效期状态 | |
| 授权类型及有效期状态 | |
| 操作设备/项目 | |
| 人员状态 | 在岗 / 离职 |

### 查询结果展示

- 列表视图，支持排序（如按到期日期排序）
- 点击人名进入详细档案页（含基础信息、证书明细、授权明细）

### 导出与打印

- 支持导出当前查询结果为 Excel / CSV
- 支持单份档案打印或批量打印（如全院 POCT 人员授权汇总表）
- 支持自定义导出字段与模板

## 4.1.5 人员培训管理

实现 POCT 培训全流程线上化管理：

| 环节 | 说明 |
|------|------|
| 培训计划 | 制定年度/季度培训计划、课程、题库，动态生成试卷（按难度系数选题，汇总分数） |
| 在线学习 | 理论学习、操作视频、课件资料 |
| 培训记录 | 自动记录培训时长、学习进度、培训签到 |
| 证书管理 | 培训合格证书自动生成、有效期提醒 |

---

## 4.1.6 人员考核管理

建立 POCT 考核标准化体系：

| 环节 | 说明 |
|------|------|
| 在线考试 | 题库管理、随机组卷、自动评分 |
| 操作考核 | 实操考核记录、评分标准管理 |
| 考核结果 | 成绩统计、不合格人员管理、补考管理 |
| 授权关联 | 考核合格自动授权，不合格锁定操作权限 |

---

## 4.1.7 报告权限管理

基于角色的精细化权限控制：

| 维度 | 说明 |
|------|------|
| 操作权限 | 设备操作、报告录入、报告审核、报告发布 |
| 数据权限 | 科室数据隔离、患者数据权限控制 |
| 权限有效期 | 临时授权、定期复审、自动失效 |
| 权限日志 | 权限变更记录、操作日志追溯 |
