# 人员管理模块 — 操作说明

## 1. 模块概述

人员管理模块覆盖 POCT 检验人员的全生命周期管理，包含**人员档案、资质证书、考核、培训、授权、报告权限**六大子模块。核心设计理念：**考核合格 → 预选 → 管理者确认 → 授权**，确保只有具备有效资质且通过考核的人员才能操作设备和出具报告。

## 3. 人员档案管理

### 3.1 新增人员

1. 进入 **人员基础信息** 页面，点击「新增」按钮
2. 填写工号（必填）、姓名（必填）、性别、出生日期、所在科室、职务/职称、学历、专业、电话、邮箱、入职日期
3. 点击「确定」保存，人员状态默认为"在岗"，考核状态默认为"未考核"

### 3.2 批量导入人员

1. 点击「导入」按钮，选择 Excel 文件（.xlsx / .xls）
2. 系统自动读取并批量创建人员记录
3. Excel 模板格式同导出格式（可先导出一份作为模板）

### 3.3 人员状态管理

- **启用/禁用**：在列表操作列点击切换开关，可在"在岗"/"离职"之间切换
- **档案查询**：进入「人员档案查询」页，可组合查询人员的证书、授权、考试、培训汇总信息；点击某行可展开详情面板

## 4. 考核管理全流程

考核管理是人员授权的核心前置条件，完整流程如下：

```
题库维护 → 自动组卷 → 发布试卷 → 在线考试 → 自动评分 → 预选 → 管理者确认合格 → 生成授权
```

### 4.1 题库维护

1. 进入 **题库** 页面
2. 点击「新增」添加题目：
   - 题目类型：单选题 / 多选题 / 判断题 / 操作题
   - 题目内容：题干文本
   - 选项：JSON 格式，如 `["A. 选项一", "B. 选项二", "C. 选项三", "D. 选项四"]`
   - 正确答案：如 `A`（单选）、`AB`（多选）、`对`（判断）
   - 难度系数：1-5（数值越大越难）
   - 题目分类：如 生化、血气、血糖
3. 也可通过「导入」按钮批量导入 Excel 题库

> **注意**：已组卷的题目即使被停用，不影响已生成试卷的内容（试卷题目为快照，生成后固定不变）。

### 4.2 自动组卷

1. 进入 **试卷** 页面，点击「自动组卷」按钮
2. **Step 1 — 策略配置**：
   - 输入试卷名称
   - 设置合格分数线（如 60 分）
   - 设置考试时长（分钟）
   - 选择题库分类（可多选：生化、血气、血糖等）
   - 配置各题型的数量和每题分值：

   | 题型 | 数量 | 分值/题 |
   |------|------|---------|
   | 单选题 | 15 | 4 |
   | 多选题 | 5 | 6 |
   | 判断题 | 5 | 2 |

3. 点击「生成预览」，系统按策略从题库随机抽题并展示试卷概览：
   - 试卷总分 = Σ(数量 × 分值)
   - 题目总数
   - 各类题型题目数
4. 确认无误后点击「保存」，试卷状态为"**未发布**"（草稿态，可被多人审阅）

> **调参重试**：如对抽题结果不满意，修改策略参数后重新点击「生成预览」即可。
> **题库不足**：若某类题目数量不够，系统会提示"题库中[单选题]题目不足，需要15题，实际8题"，需先在题库中补充。

### 4.3 发布试卷

1. 在 **试卷** 列表中找到状态为"未发布"的试卷
2. 点击操作列的「发布」按钮
3. 确认后试卷状态变为"**已发布**"，此时该试卷可被用于考试

> 只有"已发布"状态的试卷才能在考试中被引用。

### 4.4 在线考试

1. 进入 **在线考试** 页面（可从考试记录页点击"在线考试"跳转，需传入 `paperId` 和 `personId`）
2. 顶部显示试卷名称和倒计时器（最后 5 分钟变红提醒）
3. 按题目顺序作答：
   - 单选题：单选按钮组
   - 多选题：多选框组
   - 判断题：对/错单选
4. 点击「上一题」「下一题」切换，左侧显示进度（如 3/20）
5. 答完所有题目后点击「交卷」
6. 系统自动评分：
   - 比对考生答案与正确答案
   - 计算总分和正确题数
   - 判定结果：总分 ≥ 合格线 → **合格**，否则 → **不合格**
7. 显示考试结果（得分、正确题数、通过/未通过）

### 4.5 考核状态流转（预选机制）

```
未考核 ──(考试达标)──→ 预选 ──(管理者确认)──→ 合格 ──→ 自动生成授权
                            │
                            └──(管理者驳回)──→ 不合格
                                                  │
                                                  └──(补考达标)──→ 预选
```

考试达标后，人员考核状态变为"**预选**"（中间态），不会自动获得授权。必须由管理者确认：

1. 进入 **人员基础信息** 页面，点击「预选管理」按钮
2. 弹出预选人员列表（仅展示考核状态为"预选"的人员）
3. 勾选要处理的人员，点击：
   - 「确认合格」：状态变为"合格"，**自动生成一条授权记录**（操作授权，有效期 365 天）
   - 「驳回」：状态变为"不合格"，需重新考核
4. 预选超过 30 天未处理，系统会定时提醒

### 4.6 考核统计

1. 进入 **考核统计** 页面
2. 查看关键指标：
   - 总考试次数
   - 通过人数 / 不合格人数
   - 平均分
   - 通过率（进度条）
3. 下方表格展示最近的考试记录

## 5. 资质证书管理

### 5.1 新增证书

1. 进入 **资质证书** 页面，点击「新增」
2. 选择关联人员，填写证书类型（执业医师/护士/技术资格/POCT专项/仪器认证）、证书名称、编号、发证机构、发证日期、有效期至
3. 点击「确定」保存

### 5.2 上传证书附件

1. 在列表中找到目标证书，点击操作列「上传附件」
2. 选择图片或 PDF 文件上传

### 5.3 到期管理

- **即将到期提醒**：系统每日凌晨 2 点扫描证书，距到期 ≤ 90 天自动标记为"即将到期"
- **到期自动停权**：证书到期后自动标记"已过期"，并**撤销关联的有效授权**
- 点击「即将到期」按钮可筛选查看 90 天内到期的证书列表

## 6. 授权管理

### 6.1 授权前置条件

新建授权时系统自动校验：
1. 人员考核状态必须为"**合格**"（否则提示"人员考核未合格，无法授权"）
2. 人员必须有至少一个"**有效**"状态的资质证书（否则提示"人员无有效资质证书，无法授权"）

### 6.2 新增授权

1. 进入 **授权记录** 页面，点击「新增」
2. 选择人员、授权类型（操作授权/报告权限/质控权限/管理权限）、授权起止日期
3. 点击「确定」，系统自动进行前置条件校验
4. 通过后授权状态为"有效"

### 6.3 授权审批流程

适用于需要多级审批的授权场景：

1. 在 **授权审批流** 页面点击「新增」创建审批申请
2. 选择申请人、申请类型
3. 提交后状态为"待审核"
4. 审批人可在列表中操作：
   - **一级通过**（科室主管审核，记录审核时间）
   - **二级通过**（检验科/质管部门审核，状态变为"已通过"并记录完成时间）
   - **驳回**（状态变为"已驳回"）

### 6.4 授权到期

- 系统每日凌晨 4 点扫描，到期授权自动标记为"已过期"
- 手动操作：在列表操作列可撤销授权

## 7. 培训管理

### 7.1 培训计划

1. 进入 **培训计划** 页面，新增培训计划
2. 填写计划名称、类型（年度/季度）、年度、季度、课程内容、起止日期

### 7.2 培训签到

1. 进入 **培训记录** 页面，点击「签到」按钮
2. 输入人员 ID 和培训计划 ID
3. 系统自动记录签到时间，初始进度为 0%

---

## 8. 报告权限管理

1. 进入 **报告权限管理** 页面
2. 新增权限配置：
   - 选择角色（sys_role）或人员
   - 配置操作权限集合（设备操作 / 报告录入 / 报告审核 / 报告发布，可多选逗号分隔）
   - 设置数据范围（本科室 / 全院）
   - 设置生效/失效日期
