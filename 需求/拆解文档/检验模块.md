# 4.3 检验系统模块

## 4.3.1 设备数据采集

实现POCT设备检测数据的全自动、实时、可靠采集，消除人工录入环节，确保数据的及时性、准确性和完整性。

### 1. 协议支持

- 支持主流POCT设备通讯协议（如ASTM、HL7、POCT1A等）
- 支持多种物理接口采集：串口（RS232）、网口（TCP/IP）、USB、蓝牙、无线网络
- 支持不同厂商设备的协议适配与解析（如罗氏、雅培、雷度米特、理邦等）
- 提供协议扩展接口，支持新设备快速接入

### 2. 实时采集

- 检测完成后，数据自动实时上传至系统
- 采集内容包括：样本编号、患者信息、检测项目、检测结果、检测时间、设备编号、质控状态等
- 无需人工录入或扫码确认（除特殊异常情况外）
- 采集延迟不超过秒级

### 3. 数据校验

- 数据完整性校验：检查必填字段是否完整、格式是否正确
- 异常数据过滤：
  - 超出测量范围的结果自动标记
  - 重复数据自动去重
  - 无效或乱码数据自动拦截并告警
- 校验失败的数据进入异常队列，支持人工复核

### 4. 离线缓存

- 网络中断时，设备或采集终端自动切换至离线模式
- 检测数据本地缓存（加密存储）
- 网络恢复后自动上传缓存数据（断点续传）
- 缓存数据不丢失、不重复上传

## 4.3.2 检验报告管理

实现检验报告的自动生成、标准化管理与全流程审核控制，确保报告质量的规范性与危急值处理的及时性。

### 1. 报告生成

- 根据采集到的检测数据，自动生成标准化检验报告
- 报告内容包括：患者基本信息、样本信息、检测项目、结果值、参考范围、异常标识、检测设备、检测时间、报告人/审核人等
- 支持多项目组合报告
- 支持报告模板配置（医院可按需定制报告格式）

### 2. 报告审核

- 三级审核流程：检测 → 初审 → 审核 → 发布（可根据医院要求配置）
- 审核操作：通过、修改、驳回、重新检测
- 修改记录留痕：修改前/修改后内容、修改人、修改时间
- 驳回需填写驳回原因，退回至上一环节
- 已发布的报告支持撤回（需审批）

### 3. 危急值管理

- 危急值自动识别：根据项目阈值自动判断
- 实时报警：检测到危急值时，系统立即触发报警
  - 弹窗提示
  - 声音告警
  - 消息推送至医生/护士站
- 记录闭环：
  - 危急值上报时间
  - 接收人及接收时间
  - 处理措施与处理时间
  - 临床确认反馈
- 未闭环的危急值持续提醒，直至处理完成

### 4. 报告查询

- 支持多维度组合查询：
  - 患者维度：姓名、病历号、身份证号、就诊卡号
  - 时间维度：检测日期范围、报告日期范围
  - 设备维度：设备名称、设备编号、科室
  - 项目维度：检验项目名称
  - 审核状态维度：待审、已审、已发布、已驳回
- 查询结果支持列表展示与详情预览
- 支持查询结果导出（Excel）

## 4.3.3 HIS系统对接

实现POCT检验系统与医院HIS系统的无缝对接，打通信息孤岛，实现医嘱、患者信息及报告的自动流转。

### 1. 数据交互

- 患者信息自动获取：从HIS获取患者基本信息、就诊信息、科室床位等
- 医嘱信息自动获取：
  - 获取检验申请单信息
  - 支持条码/二维码扫描自动调取医嘱
  - 减少手工录入错误
- 支持双向数据同步

### 2. 报告推送

- 检验报告审核发布后，自动推送至HIS系统
- 推送内容包括：完整检验报告、危急值标识、审核人信息等
- 推送失败自动重试机制（可配置重试次数与间隔）
- 支持手动补推

### 3. 协议标准

- 支持标准医疗信息交换协议：
  - HL7（V2.x/V3）
  - WebService（SOAP/RESTful）
  - FHIR（可选）
- 支持中间表/视图方式对接（备用方案）
- 提供接口适配器，支持不同HIS厂商的定制对接

### 4. 数据同步

- 双向数据同步机制：
  - HIS → POCT：患者信息、医嘱信息
  - POCT → HIS：检验结果、报告
- 数据一致性保障：
  - 事务机制：保证双方数据同时成功或同时回滚
  - 数据对账功能：定期校验双方数据一致性
  - 差异数据自动告警，支持人工处理
